# $$\huge\color{#E5A00D}{\textsf{Plexy Audiobooks}}$$

<br clear="left"/>
<br clear="left"/>

Plexy Audiobooks is a vibe-coded audiobook player app for Android that connects directly to a Plex library, allowing for direct play of audiobook titles without connection middleware (i.e. vpn/ztna etc).

### $$\large\color{#E5A00D}{\textsf{Key Features:}}$$
- Links directly with Plex account via https://plex.tv/link
- Can switch servers and libraries
- Pulls metadata from emnbedded tags and Plex data (future plans to offload from Plex for more seamless metadata)
- Tracks book progress (Requires enabling "Store track progress" for Audiobook library in Plex)
- Can navigate audiobook chapters when available
